# BG3 队伍与剧情 0.2.6

依赖 BG3 操作风格战斗面板；配套父模块0.15.5与统一自动化修复1.0.2。提供队伍总览、移动管理、完全限制、属性／技能检定、剧情投票与三秒改票倒计时、先下手为强和队友悬停信息。主题跟随父HUD设置。

本版队伍临时生命使用独立蓝条和数字，读取实际临时HP，保留真实HP显示。规则适配调用统一引擎。剧情继续使用原生右键平移与测距，忽略平移产生的无按键模拟悬停，保留真实释放、Escape和失焦取消。

玩家请求由在线主GM核验权限与仲裁。剧情入战配合先攻栏和遭遇提示音；Dice So Nice为推荐表现依赖。使用本模块检定时停用旧独立fvtt-bg3-check。
