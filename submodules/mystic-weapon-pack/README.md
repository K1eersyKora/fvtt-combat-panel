# FVTT 物品与职业模板 1.5.0

本模组只提供图鉴和图片，没有启动脚本。自动化由 `fvtt-automation-repair` 统一执行。

提供 41 张模板：神秘武器与绝地职业 12 张，法术与职业特性 29 张。完整清单见 CATALOG.json。可从合集拖入角色卡，原神秘武器包的图片和合集 UUID 保持兼容。

新模板的次数从完整状态开始；已有角色的次数由迁移保留，不会因为安装模板包而恢复。场景中已存在的角色物品仍需由统一修复模组迁移。

依赖 FVTT 统一自动化修复 1.0.0 与 dnd5e。无需另行启用旧幸运或战斗大师模组。

安装清单：

```text
https://github.com/K1eersyKora/fvtt-combat-panel/releases/latest/download/mystic-weapon-pack.json
```
