# BG3 遭遇提示音

启用模块和 libWrapper 后，选中指示物，使用其原生 HUD 右下角的“进入战斗”。这次加入成功后，同一场景的在线客户端会听到一次提示音。4 秒后，系统会给本次加入且仍未掷先攻的单位使用原生先攻掷骰。已掷的先攻与已经移出的单位会跳过。

GM 使用原生战斗追踪器正式开始第一轮。移出战斗、追踪器换回合和刷新页面不触发这段音效。

“配置设置 → 模块设置 → BG3 遭遇提示音”可分别关闭音效与自动先攻，或调节提示音音量。播放同时受各客户端的 Foundry 界面音量控制。

音频来源：[Abadeer 的 BG3 进入战斗游戏录音](https://tuna.voicemod.net/sound/c697912d-4089-439b-aa15-8334556a3538)。


## 0.1.1 · 剧情模式接入

新增仅 GM 可调用的 api.playEncounterStart(sceneId,eventId)，复用原有音效文件、音量／开关与原生广播；同一事件 ID 去重。api.initiativeDelay=4000，api.autoInitiative() 返回原配置。原生 Token HUD 的加入战斗行为及四秒后先攻保持不变。
