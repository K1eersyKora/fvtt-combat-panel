# BG3先攻栏 0.1.3

0.1.3 过滤与当前遭遇无关的 Actor／Token 更新，避免重复重建立绘栏；补充视野刷新事件。保留全局遭遇、48px 导航避让、中文标签和原生先攻顺序。配合战斗面板 0.15.2 与队伍与剧情 0.2.2，入口 main-4.js。

Foundry VTT 13 / dnd5e 5.1 的独立子模块。顶部横排立绘参考 Carousel Combat Tracker 的紧凑布局：先攻置于左下角的 d20 骰子底框内，玩家角色中文名常驻立绘正下方；数字与名字共用字体、字号和行高。NPC／怪物不显示姓名，英文姓名部分也不进入标签或悬停提示。当前回合加高并突出边框；配色与 RGB 动画直接跟随战斗面板 HUD 齿轮设置。长中文名截断显示，悬停可读其完整中文部分。

同时启用：

- BG3操作风格战斗面板 `fvtt-combat-panel` >= 0.15.2
- BG3队伍与剧情 `fvtt-party-tools` >= 0.2.2
- BG3 遭遇提示音 `fvtt-bg3-encounter-sfx` >= 0.1.1（及其 lib-wrapper 依赖）

原生 Token 右下角“进入战斗”创建未绑定场景的遭遇时，先攻栏也会显示。新活动遭遇优先于侧栏仍在查看的旧遭遇，先手攻击入战后两端会切换到新遭遇。两侧掷骰、前后回合和开始／结束按钮下移，并避开实际场景导航条目。

启用 About Time Next／About Time 且存在 `rtAutoPauseCombat` 设置时，当前主持人加载模块会关闭该设置，屏蔽创建与结束遭遇带来的自动暂停。原有手动暂停与恢复仍可使用；剧情入战不再擅自解除手动暂停。

## 从剧情进入战斗

PL 反对过半后保留三秒“准备动手”，期间可改票。倒计时结束仍过半时，先调用 BG3 入战音效，再把本次剧情场景中非隐藏的 PL／NPC／敌人加入原生遭遇，调用系统先攻并开始第一轮。不额外等待旧音效模块的四秒自动先攻延迟，不暂停游戏。音效仍遵循原音效模块的开关和音量。

剧情开始时记录参战名单，开战时再次收集当前场景非隐藏单位，纳入剧情期间新增或显形的 NPC；先手攻击者和其实际攻击目标也纳入名单。隐藏单位不自动加入；DM 主动选择隐藏怪物发起先手时，该攻击者可以入战，原生隐藏状态保留。重试不会重复创建同一剧情的遭遇、重复添加成员或重投已有先攻。

## 先下手为强

“队伍与剧情”默认开启“剧情中允许先下手为强”世界选项。PL 在态度栏点击“先下手为强！”，DM 先选中一个怪物或角色再点击相同按钮。选中角色的原有 HUD 随即开放，可以在未进入战斗时选武器／攻击法术并指定目标；其他 PL 保持剧情界面。准备期间可取消，不创建战斗。

武器或攻击法术真实投掷后，无论命中与否，自动退出整个剧情，播放音效、掷先攻并进入战斗。Midi 使用 AttackRollComplete，原生使用公开 rollAttack 方法返回后的信号；取消投掷没有攻击信号，不触发开战。进攻性的豁免／直接伤害活动也支持：Midi 正常工作流完成后接续开战，原生在活动消费成功并生成使用卡后接续。次数、法术位、弹药和伤害继续由系统／Midi 的正常流程处理，本模块不额外扣费或退款。Midi 的先手未命中会正常收尾，避免停在手动伤害等待状态。

先手者不获得额外排序优先权，所有人仍按原生先攻开始；先手者自然投到第一时即轮到其正常回合。同一时间只开放一个先手者，并发的其他请求不会在之后自动重放。

## 先攻栏操作

- 点击自己的立绘选中该 Token；点击可见的其他单位仅平移查看，不获取其控制权。
- 悬停先攻栏显示按钮。DM 可掷尚未投的先攻、前后换回合、开始或结束战斗；PL 仅在其拥有的当前单位回合可结束回合。结束战斗使用原生确认。
- 默认向玩家隐藏非其拥有的敌方先攻数字，隐藏战斗单位不向玩家显示。立绘尺寸和显示开关为客户端设置。
- 同时启用 Carousel Combat Tracker 时，仅在本先攻栏显示期间隐藏其重复栏，保留其配置和源码。

公共接口：`game.modules.get('fvtt-bg3-initiative').api` 提供 `bar`、`refresh()`、`enterStoryEncounter(state)`；后者仅当前 activeGM 可执行，并要求匹配正在进入战斗的剧情状态。UI 复用父模块 `api.ui` v1 与主题变量，所有战斗文档由 Foundry 官方 API 创建和推进。
