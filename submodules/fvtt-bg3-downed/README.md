# BG3 倒地与死亡豁免 0.1.2

0.1.2 将全场周期扫描改为事件驱动：只有状态、可见性或地图变化时更新，地图平移与 Token 动画使用更新后的 PIXI 变换。移除空闲扫描和常驻帧循环，原生死亡豁免、轮次去重与权限保持；入口 main-3.js。

适用于 Foundry VTT 13.351 / dnd5e 5.1.10。独立模块，不依赖战斗面板；可以同时使用。

- `character` 类型角色的 HP 降至 0 时，在可见指示物头顶显示 BG3 原版濒死 UI。单纯俯卧、HP 大于 0 或 `npc` 类型不会触发。
- 左右图层独立，支持 0–2 成功与 0–2 失败的九种组合，包括 1 成功／1 失败。
- 进入自身回合，由当前主 GM 调用原生 `actor.rollDeathSave()`，保留系统和现有 Midi 的修正及原生聊天结果。
- 每名参战者每轮最多自动投一次；回退／重进同一轮、刷新、多个 GM 客户端不补投。没有 GM 在线时不会自动投。
- 原生第三次成功清零计数时，同步保存稳定标记；稳定后停止自动投，受到原生伤害、重设死亡豁免或恢复 HP 时清除标记。三次失败显示死亡，自然 20 恢复 HP 后移除 UI。不会因为生命值归零强行修改俯卧／昏迷效果。
- 图标保持屏幕尺寸并跟随地图平移、缩放和 Token 移动；遵守 Token 可见性，不向玩家展示隐藏 Token。

在“管理模组”启用“BG3 倒地与死亡豁免”并重新加载世界。设置中可关闭指示器、关闭自动投掷、调整每客户端图标宽度。角色卡手动死亡豁免同样更新图层与稳定标记。

本模块不改第三方代码、不会自行推进回合，也不接管伤害导致的死亡豁免失败结算。若另装自动死亡豁免模块，应只启用一处回合自动投掷；本模块会识别已完成的当回合原生死亡豁免。

素材为此前本机 `Game.pak` 中的 BG3 `Overhead/Downed` 图层及 `PlayerPortraits/ico_downed`，依原版 `Overhead.DeathSavingThrow` 模板定位。原始素材说明在此保留。
