# 配套自动化修复的作用 · 1.0.2

统一引擎将规则、物品匹配和旧宏路由集中在一个模块。战斗面板负责用户操作；实际资源、攻击、伤害、豁免及效果继续接入 D&D5e、Midi-QOL、Chris's Premades 和 DAE 等已有能力。

## 修复范围

| 类别 | 承接与修复的作用 |
| --- | --- |
| HUD 结算适配 | 统一动作状态、免费次数／免费护盾反应、魔法飞弹等多目标准备、原生范围选择、黎明曙光自由选取和已配置的传送落点流程；保留逐角色等待与取消 |
| 圣武士／光明牧师 | 免费至圣斩资源提交、圣洁武器魅力命中加值、圣疗、守御之光，以及神导术等相关卡片匹配；神导术采用本项目「属性与技能检定 +1d4」房规 |
| 攻击附伤与逐束法术 | 接入已配置的咒唤微元素群、魂灵环绕、猎人印记、脆弱诅咒和魔能爆；实际条件与逐束分配沿用适用的 CPR／Midi 自动化 |

## 本次值得关注的修复

- **免费至圣斩**：法术位为零仍可使用有效免费来源，只扣一次对应次数。
- **幽魂视界弓**：普通攻击、视界与暴击资源分开；长休恢复相应资源，同回合重复强制暴击受到限制。
- **恐惧伏击**：可与猎人印记同时附伤，暴击各自加倍，同回合不重复消费伏击。
- **仇敌誓言**：受标记目标降至 0 HP 后可免费转赠，不再次扣引导神力，不重置原持续时间终点。
- **元素吸收／暮色庇护所**：前者连接当前 CPR 反应抗性，后者在相应回合结束授予临时生命。
- **海德**：持续攻击只产生一次伤害；模板随棋子移动，在关联效果结束时清理。
- **月德变形**：变形和解除时保留专注、重绑相关外部效果与模板引用；用于维持专注的数据不会开放兽形原本不能施放的法术。
- **玩家豁免结算**：替换已定位的旧 TokenBar 无超时等待路径，接续原生自动豁免，保留 GM／玩家正常仲裁。
- **2014 医疗包（1.0.1）**：稳定 0 HP 目标，保留规则版本、ID、数量与次数；无目标、健康或死亡目标在扣费前中止，并修复已确认的历史活动字典坏结构。
- **魅影之力（1.0.2）**：比较明确指定的目标字段，保留 Foundry 补全默认值，正确卡片再次迁移不重复写入。

## 依赖与使用

必须启用 Midi-QOL、Chris's Premades、DAE、Socketlib、libWrapper、Times Up 和 Midi Item Showcase Community ≥ 1.6.2。GP 匕首之云需要启用 Gambit's Premades 和 Region Attacher。动画和媒体还受原物品及第三方配置影响。

只需规则引擎时，可不启用父 HUD 和界面子模组。需要模板时，再启用 `mystic-weapon-pack` 1.5.0，从两个图鉴拖入需要的物品。旧 `fvtt-lucky`、`fvtt-battle-master` 及旧神秘武器包执行脚本应停用或升级，避免重复规则钩子。

GM API：

```js
const api = game.modules.get("fvtt-automation-repair").api;
const inventory = await api.migrateWorld({ apply: false });
console.log(inventory);
const snapshot = api.snapshotWorld();
```

`apply:false` 返回世界、角色、物品与模块清单，不写入，也不是每一项改动的差异预览。`snapshotWorld()` 返回可保存的世界 API 快照，包含角色、物品、宏、场景、战斗、消息、时间／暂停及相关设置；不代替 Foundry 整个世界目录、用户数据与素材备份。

实际迁移通过 `api.migrateWorld({apply:true, backup})` 执行。必须由 GM 提供能够实际保存快照、成功后才返回的 `backup(snapshot)` 回调；未提供备份回调会拒绝执行。先离线备份世界目录，再按 [升级说明](UPGRADING.md)安排维护并检查返回的 `errors`、`changes` 和各步骤报告。不要用空回调绕过备份。

## 验证边界

已有本地真实 GM／普通玩家针对性测试覆盖免费至圣斩、弓资源、恐惧伏击与猎人印记、仇敌誓言、抗性、暮色临时生命、海德、月德变形、玩家对 NPC／玩家豁免、幸运与精准、实际模板宏和医疗包。五个服务器世界迁移错误为 0，复跑改动为 0，资源审计通过。

元素吸收验证了抗性与后续附伤效果生成，本轮没有实际打出该次附伤。中央宏的编译检查不等于每个分支均实战运行。已有丢失的月德范围模板无法推断旧位置，需要重新施法。未验证 V14、其他系统大版本、实体音频播放或所有第三方组合；未把已定位的等待问题泛化为所有未知卡片问题。
