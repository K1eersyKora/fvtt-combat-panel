# 三维跑团与方块建造上手


主持人（GM）可根据场景选择三维运行工具或方块建模工具。

| 工具 | 版本 | 用途 |
|---|---|---|
| fvtt-3d-tabletop | 0.1.7 | 普通三维跑团 |
| fvtt-mc-builder | 0.6.8 | 自建方块场景 |

## 安装前提


安装任一工具前，请先准备以下依赖。

- 具有使用权的 3D Canvas（levels-3d-preview 8.x）
- libWrapper

安装清单地址见仓库 `K1eersyKora/fvtt-combat-panel` 的 [README 安装表](../README.md)。

两者在相机、高低差和特效上有功能重叠。请用不同的测试世界分开验证，不要同时启用重叠的处理。

## 启用步骤（GM）


1. 备份世界。
2. 在“管理模组”里勾选你选用的工具。
3. 先确认有一个可以正常进入的三维场景，再检查工具功能。

## 三维跑团（fvtt-3d-tabletop）


**镜头**（启用后生效）

- `W` `A` `S` `D`：平移
- `Q` / `E`：绕中心旋转
- 滚轮：缩放
- 灵敏度为客户端设置，每位玩家可自行调整

**高地规则（可选）**

- 只在开启后生效，且只应用于三维场景中的 D&D5e 攻击活动。
- 攻击者与目标高差至少 5 英尺时，高处攻击低处获得优势，低处攻击高处获得劣势。
- 结果会与已有的优势/劣势合并。

**显示与动画**

- 显示范围与专注。
- 提供施法动画。

## 方块建造（fvtt-mc-builder）


建造是 GM 操作。首次打开“方块建造”，点“新建方块地图”并进入新场景，再点“开始建造”进入编辑，可在列表中选方块、切换样式，或用搜索查找。

| 操作 | 按键 |
|---|---|
| 放置 | 左键 |
| 拆除 | 右键 |
| 旋转 | `R` |
| 切换视角 | `Alt` |
| 退出 | `Esc` |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Y` |

注意：很多物件仅作布景，没有额外功能。例如火盆用的是发光材质，不等于场景灯；需要照明时仍要另外放置灯光。

**第一次试建**

1. 在新建的方块地图里布一段地面、一个转角和一扇门，退出建造模式。
2. 分别用普通玩家账号和 GM 账号，在同一位置检查：
   - 双向移动（走过去、走回来）
   - 开门与关门
   - 战争迷雾
   - 权限

复杂地形的尺度、导出和验收方法见 [3D 地图生成与排错](3D-MAP-GUIDE.md)。
