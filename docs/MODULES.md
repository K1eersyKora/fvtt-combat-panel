# 模组功能与依赖 · 0.15.5 套件

## 战斗面板 0.15.5

`fvtt-combat-panel` 提供底部装备／特性／法术栏、行动与法术位资源、免费来源、目标与范围准备、多目标计数和确认、只读命中／伤害预测、准备音效及取消结算。不同角色的工作流独立，GM 切换角色不会将前一个角色的等待转给新角色。

外观设置包含透明／深棕背景、缩放、栏位与行数、职业图标、自定义调色与用户预设、两套颜色的 RGB 渐变。自动／低配／完整档按客户端保存；低配减轻模糊、动画、音频预载和独立骰盘开销，保留骰值与资源结算。

必须启用统一自动化修复；多目标、范围、传送、免费资源与动作状态通过统一实现执行。队伍与剧情等功能由下列子模组提供。

## 队伍与剧情 0.2.6

`fvtt-party-tools` 需要战斗面板。它提供队伍总览、移动管理和完全限制模式、BG3 属性／技能检定、剧情电影界面、态度投票与三秒改票倒计时、先下手为强、队友悬停信息。临时生命显示为独立蓝色条和数字，实际 HP 与临时 HP 分别读取。

剧情支持原生右键平移和原生测距，修复平移产生的模拟悬停事件误中止真实拖动的问题。主题和 RGB 跟随父 HUD。玩家请求经当前用户的请求记录提交，由在线 activeGM 核验控制权并仲裁；玩家不能直接替 GM 创建遭遇。

使用其检定功能时停用旧独立 `fvtt-bg3-check`。Dice So Nice 为推荐表现依赖；剧情自动入战配合先攻栏和入战音效。

## 先攻栏 0.1.4

`fvtt-bg3-initiative` 依赖战斗面板、队伍与剧情及遭遇提示音。顶部立绘按原生先攻排序与回合轮转显示；先攻数字放在左下 d20 底框，玩家角色中文名在立绘下方，NPC 不展示姓名。隐藏单位及玩家不可见数据遵循原生权限。

GM 右键立绘可「设为当前回合」，不重投先攻或修改轮数；菜单绑定原参战者，重新排序或删除目标后不会切到错误角色。轮数标记随原生第一名移动和滚动。玩家可选择自己控制的单位，按权限结束自己的回合，不能使用 GM 跳转。

剧情多数反对倒计时完成或先手攻击实际提交后，统一接续音效、原生遭遇、先攻和第一轮；取消准备不会因此开战。原生 Token HUD 创建的全局遭遇也能显示。此流程不额外等待音效模块原生 Token HUD 路径的四秒延迟。若存在 About Time 入战自动暂停设置，会关闭该项；保留手动暂停。

## 倒地与死亡豁免 0.1.2

`fvtt-bg3-downed` 可以独立启用，不要求父 HUD。对 `character` 类型、0 HP 且可见的 Token 显示成功／失败刻度；NPC、仅俯卧或 HP 大于 0 不触发。稳定、死亡和恢复 HP 按实际状态显示或结束。

进入自身回合，由在线主 GM 调用 D&D5e 原生死亡豁免；同一参战者每轮去重，回退、重进或多个 GM 不补投。设置可关闭自动投掷或调整客户端图标宽度。若另有自动死亡豁免模块，应仅保留一处自动调用。

## 遭遇提示音 0.1.1

`fvtt-bg3-encounter-sfx` 仅直接依赖 libWrapper。通过原生 Token HUD 成功加入战斗后，同场景客户端播放一次提示音；可选四秒后为本次加入且未掷先攻的单位调用原生先攻。刷新、移出战斗、切换回合不重复触发，原生路径仍由 GM 正式开始战斗。

另提供 GM 剧情入战音效接口，复用开关、音量与事件去重。音量同时受各客户端 Foundry 界面音量控制。音频来源：[Abadeer 的 BG3 游戏录音](https://tuna.voicemod.net/sound/c697912d-4089-439b-aa15-8334556a3538)。

## 统一自动化修复 1.0.2

`fvtt-automation-repair` 是规则与兼容引擎。它集中执行职业、法术、武器、幸运、战斗大师和旧 DSH 修复；提供中央宏注册表、HUD 结算适配与世界迁移。它可以不启用战斗面板，但需要自身列出的第三方自动化依赖。

修复范围和实例见 [AUTOMATION.md](AUTOMATION.md)。旧 `fvtt-lucky` 和 `fvtt-battle-master` 应停用；旧神秘武器包需升级为下面的纯模板包。

## 物品与职业模板 1.5.0

`mystic-weapon-pack` 保留原模块 ID、图片路径和旧合集 UUID，提供 12 张神秘武器／绝地职业模板及 29 张法术／职业模板。没有启动脚本，物品宏只调用统一引擎，不再嵌入第二套完整实现。

可从图鉴拖入角色卡；新模板从完整次数开始。已有角色资源通过迁移保留，安装模板包不会代替存量卡片迁移。详见 [41 项目录](ITEM-CATALOG.md) 和源码 `submodules/mystic-weapon-pack/sources/`。

## 推荐组合

| 需要的体验 | 本仓库需启用的模组 |
| --- | --- |
| 底部战斗操作 | 自动化修复 + 战斗面板 |
| 队伍、检定与剧情界面 | 上述两项 + 队伍与剧情 |
| 剧情自动入战与顶部先攻 | 上述三项 + 遭遇提示音 + 先攻栏 |
| 濒死指示与原生死亡豁免 | 倒地与死亡豁免，可单独使用 |

统一引擎的第三方依赖须另外安装；这些组合不是第三方依赖的替代品。完整安装方法见 [UPGRADING.md](UPGRADING.md)。
