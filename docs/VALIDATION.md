# v0.15.16 验证范围

此次发布检查九份清单、运行时入口、打包目录、脚本依赖、公开下载哈希和模板图鉴。发行附件提供 `release-validation.json` 与 `SHA256SUMS.txt`。

2026-11-21 的功能验证包括普通玩家实际瞄准、移出、Esc 和连续划过多个棋子。最新双红标效果在沿用同一锁框实现的本机 0.12.30 回植版实测。主线 0.15.16 的入口与依赖另做静态检查。在 GTX 1080、100 枚棋子的二维场景、60 FPS 上限下，各动作约为 58 FPS。同一镜头轮廓取样显示最窄红白净距约 4.34 px。

先攻 0.1.6 取自验收的完整运行目录。模板、自动化以及三维工具沿用各模块先前的独立功能验收。建图指南中的风骸岛通行、雾和帧率数值来自对应地图版本和指定路线。此次 GitHub 发布未重跑全部九模块联合游戏流程，也未在 Foundry V14 或其他大版本系统上验收。

更新说明、面板使用指南、三维工具使用指南和三维建图指南由 Claude Fable 5.2 起草，发布前按模块源码、清单与项目实测记录校订。
