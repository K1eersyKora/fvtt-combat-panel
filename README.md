父 HUD 与子模块不再常驻空闲刷新。修复刷新页面时原生角色已选中而 HUD 未同步的问题。外观 CSS 由 Claude Opus 5.5 编写，经本地 GM／双玩家复核；资源格尺寸与居中、先攻名字和数字位置保持。源码入口 main-199.js；完整验证见工作区 maintenance/combat-panel/REPORT-0.15.2-local.md。此版本为本地交付，未自动部署或发布。

# 战斗面板 0.15.0

## 紧凑准备界面

施法、特性与武器准备卡统一四周内边距，不再预留空的资源列或删除按钮顶栏。法术卡复用法术位栏的填充／空心方格，上方仅显示小号罗马环阶；戏法显示小字和空心方格，省去动作文字。特性与武器保留使用／动作信息，按实际内容宽高排版。「＋」为紧凑按钮。免费来源的删除按钮与对应卡片并排，独立点击。

多目标准备的目标计数／说明、撤回／施放和环阶卡横向排列，环阶卡保持同一排；超过屏幕可用宽度时自动换行。准备面板使用独立可读尺寸，空间不足以放在资源栏旁时移到资源栏上方。完整物品名仍可在原技能或卡片的悬浮说明查看。

0.13.2 先在独立本地实例验证与截图，未替换正式本地安装或部署服务器。

## 传送落点选择

面板会读取当前活动实际绑定的 CPR、Midi／ItemMacro 自动化及 Automated Animations 传送预设。自身传送选定施放方式／资源后直接进入原有落点选择，单一活动默认资源可用时点击技能即可开始，不需要先点一个生物。支持迷踪步、云之远迹、鸦后祝福、妖精步、星光步、月光步、渺远步、雷霆步以及同类已配置自动化的活动。

同伴选择、季节效果、范围豁免与伤害继续由原宏处理；多活动卡仍保留使用方式选择。传送他人的法术及先攻击再传送的能力继续选择对应生物。只调整本次施放的临时活动，不修改保存的角色卡、宏、距离或资源绑定。

## 黎明曙光范围自由点选

2024 版黎明曙光从底部特性栏进入后，会固定显示以牧师为中心的原生作用范围（标准卡为 30 尺）。在范围内逐个点选敌人，再点一次取消选择，数量不限；点击「确认施放」才消耗一次引导神力并统一结算体质豁免与伤害。Esc 或右键取消不会消耗资源，目标移出范围会取消选择。范围选择面板保留完整计数和并排确认按钮。

同样支持显式设置为可选择、人数不限的自身圆形／方形半径／发散范围；继续遵守活动的敌我目标条件与当前范围筛选设置。有限人数、2014 自动范围和普通范围模板保留原流程。卡片不需要迁移；原生活动、公式和资源绑定保持。

## HUD 布局与选择卡

资源栏固定贴合技能区，两行等高度下头像、职业图标和武器图标跟随技能区垂直中线，头像与职业图标保持稳定对齐。装备／特性选择优先从资源栏左侧展开，法术优先从右侧展开；选择卡保持独立可读字号，完整显示使用方式与动作类型，次数只用填充／空心图标表示。已用法术位显示为空心细线；免费施法／免费特性采用紫色资源卡，删除按钮紧邻对应卡片；不显示来源名或剩余／已用说明。

匕首之云的大体型占格判定补齐 Token 默认位置／尺寸，按所属场景网格计算；修复区域成员索引不会补扣伤害。保留当前区域脚本与每回合去重，不扩大模板。

持续法术卡片匹配：巫术箭的首次攻击与附赠动作分开，持续效果使用完整一分钟；GP 匕首之云使用现版进入区域／回合结束事件，按原文直接结算伤害。新导入角色和物品也会匹配，现有卡片可由 GM 调用 matchOngoingSpells 幂等修复。

魔法飞弹支持普通 D&D5e 伤害活动和 CPR 分弹活动。优先沿用有效 CPR 标记；普通卡片使用当前选择的伤害活动，或唯一可用的伤害活动。存在多个候选时要求明确选择，逐枚飞弹仍只在第一次扣除资源。

## 圣武士与光明牧师自动化

本地物品栏的「圣武士与光明牧师自动化」文件夹提供十二张模板。「匹配圣武士与光明牧师自动化」宏在选中角色时备份并原位更新相关卡片，未选中角色时生成模板。

圣疗使用原生治疗量选择窗口。圣洁武器消耗一次引导神力，使自身全部武器攻击获得魅力调整值命中加值，最低为+1，持续10分钟。守御之光按牧师与受攻击队友之间的30尺距离询问反应，接受后消耗一次次数与反应，并使该次攻击具有劣势。

神导术按村规应用一个全部属性及技能检定+1d4的效果。新导入玩家角色的神导术也会自动采用此规则。英雄气概、防护善恶可以通过面板指定队友，恶言相加应用下次攻击劣势。自身原点范围攻击排除施法者，龙裔锥形与线形吐息各自单独结算伤害，自施法完成或取消后清理目标标记。至圣斩在资源提交时重新核对免费次数及法术位。

- 左侧「指示物控件」中的「显示／隐藏战斗 HUD」按钮可切换底部技能栏。GM 和玩家各自控制当前会话的显示状态，重新进入世界时默认开启。

- 施法、攻击及等待豁免只占用发起角色自己的面板。GM 可切换其他角色继续行动；切回原角色可查看并取消其结算。
- 结算完成、取消及多发射线按原角色和本次工作流分别处理，保留其他角色新选的技能与目标。
- 保留本地 0.12.9 的 Rutz 3D 目标预测、锁链坐标适配与“优势 / 劣势 / 均势”文案。

- 头像左侧自动使用十二职业 BG3 透明图标；等级最高职业优先，同级优先初始职业。
- 点击头像打开角色卡。
- 齿轮 → HUD 背景：透明（保留黑色边框） / 原版深棕色。
- 短休 / 结束回合上方的百分比按钮打开缩放滑条；最低 65%，最高 150%，受可用屏幕空间限制；恢复 100% 按钮可复位。
- 背景与缩放按用户保存。原有分栏、行数、物品顺序仍按角色保存。

## 附伤法术与魔能爆

战斗面板 0.12.13 可以匹配已启用的 Chris's Premades 和 Midi-QOL 自动化。支持 2024 咒唤微元素群、魂灵环绕、猎人印记、脆弱诅咒和魔能爆。

由主持人导入并运行「匹配附伤法术与魔能爆」宏。选中角色 Token 时，宏备份并原位匹配其法术。未选中 Token 时，宏会在物品栏的「附伤与逐束法术」文件夹生成可拖入角色卡的模板。已有自定义自动化或正在持续的法术会在匹配结果中提示。

咒唤微元素群按施法环位和距离加伤，保留每次命中的元素类型选择。魂灵环绕在施法时选择伤害类型，之后随合格命中结算。猎人印记和脆弱诅咒按受标记或诅咒的目标结算。

魔能爆可在面板中选候选目标，再由 CPR 分配光束。只有一个目标时，全部光束依次攻击该目标。

## 安装与更新

在 Foundry 设置页打开「附加模组 → 安装模组」，将下面的地址粘贴到 Manifest URL 并安装。

```text
https://github.com/K1eersyKora/fvtt-combat-panel/releases/latest/download/module.json
```

安装后在世界的「管理模组」中启用战斗面板。后续在设置页点击模组的更新按钮检查新版本。

发布新版时递增 `module.json` 的 `version`，将 `download` 中的版本标签改成对应的新标签，并在该标签的 GitHub Release 中上传 `module.json` 和 `fvtt-combat-panel.zip`。正式版本设为 Latest，`manifest` 地址持续使用上面的固定链接。

## 0.13.4 · 设置与自由调色盘（本地验证）

基础设置采用无滚动条布局；装备、特性、法术、附赠在同一窗口内展开，左上角返回。窄屏分为基础设置与调色盘两页。

点击任一色块打开自由调色盘，支持色相、饱和度、亮度、HEX 和 RGB 输入；分别调节高光、边缘起色、边缘终色、基础底色。当前用户可保存、命名、更新、切换和删除多套预设。RGB 可在两套预设之间平滑往返，单程 2–30 秒，关闭后恢复静态配色。

实际交互与 GM／玩家权限验证见 maintenance/combat-panel/REPORT-0.13.4-local.md。本轮仅本地源码和隔离实例验证，未安装正式本地、未部署服务器。
