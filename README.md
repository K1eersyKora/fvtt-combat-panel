# fvtt-combat-panel

Token 旁战斗面板（Foundry VTT 13.351 / dnd5e 5.1.10）。

## 功能

- **Token 上方**：AC、当前/最大生命、临时生命。
- **Token 右侧**：动作、附赠动作、反应（来源 midi-qol 的 `actions` flag）与专注状态。
- **Token 左侧**：装备 / 特性 / 法术三级菜单。
  - 第一级：分类按钮（竖排）。
  - 第二级：点击分类展开条目，再点条目展开活动（只有一个活动的条目直接执行）。
  - 法术条目悬停时，在右侧显示对应环位的法术位剩余/已消耗（戏法显示不消耗）。
- **自定义显示**：菜单顶部「✎ 编辑」可勾选哪些条目显示在面板里，按分类分别保存到角色 actor 的
  `flags.fvtt-combat-panel.favorites`。未编辑过的角色默认显示全部条目。
- **连线**：一条 SVG 虚线从菜单指向当前 Token，表示面板所属。
- **权限**：玩家只操作自己拥有（owner）的 Token 面板；拖拽可选择可见的非自有目标，隐藏或不可见目标不会被选中。
- **菜单展开**：分类栏是固定锚点，手动移动后仍保持原位；子菜单向左展开、向右收回，靠近屏幕边缘时缩窄并滚动。
- **攻击锁链**：从所属 Token 边缘连接到拖拽指示环，跟随地图缩放和平移；锁定目标时高亮，Esc、失焦或取消拖拽时清除。
- **预测卡片**：只显示命中率估算、难易文本、攻击/豁免模式和基础平均伤害四项；不再显示来源、依据和警告。豁免活动显示的是目标豁免失败率。

所有面板元素是屏幕空间固定像素尺寸，不随地图缩放。

## 执行方式

点击条目调用角色卡上真实的 `activity.use()`，底层仍是 dnd5e / midi-qol / DAE 的原有自动化，
不绕过任何现有规则与消耗逻辑。

## 安装

```powershell
powershell -ExecutionPolicy Bypass -File tools\ui\reinstall-combat-panel.ps1
```

脚本会停掉本地 Foundry、复制 `mods\fvtt-combat-panel` 到 `Data\modules\`、重启世界。
新模块需在世界配置里启用（可用 exec-local-gm 写 `core.moduleConfiguration`）。

### v0.1.23 预测边界

预测读取当前已生效数据，不掷骰、不触发攻击工作流、不消耗资源。仅持有一项能力不会自动获得其优势。未激活或未绑定目标的能力、尚未选择的可选加值、动态掩护/夹击及自定义宏，仍记录在内部诊断中，但按用户要求不显示条件提示；最终结算以实际工作流为准。基础平均伤害没有乘命中率，也未穷举抗性、暴击和命中后触发伤害。

回归命令：`node tools/ui/test-panel-prediction.mjs`、`node tools/ui/test-panel-layout.mjs`；真实界面检查：`node tools/ui/verify-panel-v023.mjs`（GM）、`--player <玩家名>`（玩家）、`--server`（服务器）。实际结果以 `maintenance/combat-panel/TESTING.md` 和 `maintenance/combat-panel/evidence/v023/` 为准。
