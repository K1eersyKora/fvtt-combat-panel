- 左侧「指示物控件」中的「显示／隐藏战斗 HUD」按钮可切换底部技能栏。GM 和玩家各自控制当前会话的显示状态，重新进入世界时默认开启。

- 施法、攻击及等待豁免只占用发起角色自己的面板。GM 可切换其他角色继续行动；切回原角色可查看并取消其结算。
- 结算完成、取消及多发射线按原角色和本次工作流分别处理，保留其他角色新选的技能与目标。
- 保留本地 0.12.9 的 Rutz 3D 目标预测、锁链坐标适配与“优势 / 劣势 / 均势”文案。

- 头像左侧自动使用十二职业 BG3 透明图标；等级最高职业优先，同级优先初始职业。
- 点击头像打开角色卡。
- 齿轮 → HUD 背景：透明（保留黑色边框） / 原版深棕色。
- 短休 / 结束回合上方的百分比按钮打开缩放滑条；最低 70%，最高 150%，受可用屏幕空间限制；恢复 100% 按钮可复位。
- 背景与缩放按用户保存。原有分栏、行数、物品顺序仍按角色保存。

## 附伤法术与魔能爆

战斗面板 0.12.13 可以匹配已启用的 Chris's Premades 和 Midi-QOL 自动化。支持 2024 咒唤微元素群、魂灵环绕、猎人印记、脆弱诅咒和魔能爆。

由主持人导入并运行「匹配附伤法术与魔能爆」宏。选中角色 Token 时，宏备份并原位匹配其法术。未选中 Token 时，宏会在物品栏的「附伤与逐束法术」文件夹生成可拖入角色卡的模板。已有自定义自动化或正在持续的法术会在匹配结果中提示。

咒唤微元素群按施法环位和距离加伤，保留每次命中的元素类型选择。魂灵环绕在施法时选择伤害类型，之后随合格命中结算。猎人印记和脆弱诅咒按受标记或诅咒的目标结算。

魔能爆可在面板中选候选目标，再由 CPR 分配光束。只有一个目标时，全部光束依次攻击该目标。

## 安装与更新

在 Foundry 设置页打开「附加模组 → 安装模组」，将下面的地址粘贴到 Manifest URL 并安装。

```text
https://github.com/K1eersyKora/fvtt-combat-panel/releases/latest/download/module.json
```

安装后在世界的「管理模组」中启用战斗面板。后续在设置页点击模组的更新按钮检查新版本。

发布新版时递增 `module.json` 的 `version`，将 `download` 中的版本标签改成对应的新标签，并在该标签的 GitHub Release 中上传 `module.json` 和 `fvtt-combat-panel.zip`。正式版本设为 Latest，`manifest` 地址持续使用上面的固定链接。
